# Design System — ercumenterden.com

This document establishes the official color values, typography mappings, and spacing standards.

## Colors
- `--ink` (`#0A0C0F`): Deep steel background
- `--surface-1` (`#0F1114`): Standard component and card background
- `--surface-2` (`#151820`): Component background during user interaction/hover
- `--surface-3` (`#1C2028`): Deep accent backgrounds
- `--rule` (`rgba(200,194,180, 0.10)`): Soft boundaries
- `--rule-strong` (`rgba(200,194,180, 0.18)`): Defined borders
- `--platin` (`#C8C2B4`): Primary accent (neutral industrial color)
- `--text` (`#E8E4DC`): Primary readable text

## Typography Rules
1. **Cormorant Garamond 700 Italic (Serif):**
   - Hero name
   - Major section manifesto blockquotes
   - Platform names inside portfolios cards
2. **Inter (Sans-serif):**
   - All body content, descriptions, and paragraphs.
3. **JetBrains Mono (Mono):**
   - Navigational links, buttons, eyebrows, badges, and numeric labels.

## Borders
- Button corners must use `border-radius: 2px` (sharp, minimal corners).
- Cards and panels can use `border-radius: 10px` or `border-radius: 12px`.
