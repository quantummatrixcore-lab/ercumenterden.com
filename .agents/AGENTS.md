## Hard Rules — NEVER VIOLATE
- NO glassmorphism, NO neon colors, NO gradient mesh backgrounds
- NO JS-dependent counters or numbers (all static HTML)
- NO border-radius > 2px on buttons (sharp, not rounded)
- NO phone numbers anywhere on the site
- NO generic methodology sections ("Hızlı İterasyon", "AI-Native" without proof)
- Cormorant Garamond italic ONLY for: hero name, manifesto quote, platform card names
- JetBrains Mono for ALL: nav links, CTA text, metric labels, badges, eyebrow text
- prefers-reduced-motion must be respected on all animations
- CSS-only animations only (no JS animation libraries)
- All CSS variables derived from design tokens above
