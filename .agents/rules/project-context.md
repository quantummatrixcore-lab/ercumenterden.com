# Project Context — ercumenterden.com

This document establishes the project baseline for the development team.

## Tech Stack
- **Framework:** Next.js 15+ (App Router)
- **Styling:** Tailwind CSS v4, custom utility variables in CSS
- **Programming Language:** TypeScript (strict mode)
- **Deployment Platform:** Vercel (Frankfurt region `fra1`)
- **Node Environment:** 20+ LTS

## Directory Mapping
- `/app` or `/src/app`: Page routing, layouts, and route definitions.
- `/components` or `/src/components`: UI structures and sectional pages.
- `/.agents`: Context, custom skills, rules, and workflows for Antigravity.
- `/public`: Static media, favicon, sitemaps, and search engine declarations.
