## ⚡ Technical Architecture

Built with extreme performance and zero-dependency discipline:

* **Engine**: Next.js 16.3 (Turbopack static pre-rendering, SSG)
* **Runtime**: React 19.2 Server Components
* **Styling**: Tailwind CSS v4 (@theme tokens, deep onyx theme `#05070C`, cyan accents `#00F0FF`)
* **Localization**: Zero-layout-shift dual language routing (`/tr` and `/en`)
* **Deployment**: Cloudflare Edge Network / Static Export (`out/`)
* **Typography**: Geist Sans & JetBrains Mono
